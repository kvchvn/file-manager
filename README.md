### File-manager
___

This is the 2nd task made as part of the Rolling Scopes School's Node.js [course](https://rs.school/courses/nodejs).  

The task is to implement File Manager using Node.js APIs.

The file manager should be able to do the following:
- Work using CLI
- Perform basic file operations (copy, move, delete, rename, etc.)
- Utilize Streams API
- Get information about the host machine operating system
- Perform hash calculations
- Compress and decompress files

Full description and abilities see [here](https://github.com/AlreadyBored/nodejs-assignments/blob/main/assignments/file-manager/assignment.md).
